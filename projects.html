  • Deadlock StatTool

    In progress

    A command-line tool and Discord bot for checking stats in the game Deadlock, built on the free community Deadlock API.

    The CLI covers match history, per-hero stats, a coach command that compares you to the average player at your rank, item win rates against specific enemies, and a draft win-chance estimate. The Discord bot reuses the same API and stats code behind slash commands, stores linked accounts in SQLite, and caches responses so a busy server doesn't hammer the API. Tests run offline against fake data shaped like real responses. 

    # find yourself, then save your account
deadlock search "your steam name"
deadlock set-me 123456789

# win rate, KDA, rank, top heroes, recent trend
deadlock summary

# you vs. the average player at your rank on one hero
deadlock coach haze

# best items for Haze when facing Infernus
deadlock items haze --vs infernus

    Built with Python, Typer, Rich, httpx, discord.py, SQLite, pytest
